# NeuroSight — Brain MRI Classifier

An educational Streamlit project that classifies brain MRI images into four dataset categories and displays a Grad-CAM visualization.

> **Disclaimer:** This is an educational project, not a medical device. It must not be used to diagnose or guide treatment.

## Classes

- Glioma
- Meningioma
- No tumor
- Pituitary tumor

## Run locally

Requires Python and the packages listed in `requirements.txt`.

```powershell
python -m pip install -r requirements.txt
python -m streamlit run .\app\streamlit_app.py
